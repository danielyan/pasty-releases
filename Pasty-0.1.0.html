Pasty 0.1.0

Pasty 0.1.0 — first release.

- Double-tap ⌃ to open a terminal-style compose box; ⌘↩ copies the text and closes it.
- Double-tap ⌥ to open it with the clipboard contents, ready to edit.
- Esc closes without copying; the text is kept for next time.
- Settings in ~/.config/pasty/config.json (Settings… in the menu).
- Double-tap shortcuts need Input Monitoring permission; Pasty asks on first launch.
- Updates itself through Sparkle.
